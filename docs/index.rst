.. highlight:: python

Solve123d is a python based geometric constraints solver primarily intended for `build123d <https://build123d.readthedocs.io/>`

It provides a general purpose non linear equation solver (usable in any number of dimensions), and a turtle graphics inspired API for 
2D sketching, with a "smart" turtle that can calculate its moves to satisfy constraints.
